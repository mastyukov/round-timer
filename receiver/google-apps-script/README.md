# Google Apps Script receiver — пока НЕ развёрнут

Этот код — кандидат на **бесплатный HTTPS-приёмник только технических ошибок**. Сервер превращает однотипные события в дневные счётчики и записывает их в закрытую Google Таблицу (доступна владельцу скрипта).

До подключения нужен Google-аккаунт владельца и отдельная синтетическая проверка доступности из России.

## Одна первичная настройка

1. Создать новый проект в https://script.google.com/home/projects/create.
2. Вставить содержимое `Code.gs` в проект.
3. **Deploy → New deployment → Web app**, Execute as: **Me**, Who has access: **Anyone**. Подтвердить запрашиваемые разрешения Google.
4. Скопировать `/exec` HTTPS URL (не секрет; нельзя включать в приложение до проверки).
5. Проверить передачу **только синтетических** ошибок и появление приватной таблицы с агрегированными счетчиками.
6. Проверить на iPhone без VPN, а также ограничение 200 событий/сутки и отсутствие персональных полей.

## Ограничения и угрозы

- Развёрнутое веб-приложение доступно анонимно, поэтому возможны ложные события и попытки исчерпания квот. Не использовать как средство безопасности или аудита.
- Google может обрабатывать IP и другую сетевую метаинформацию, хотя в таблицу эти сведения не записываются.
- Ответ на междоменный `no-cors` запрос непрозрачен для браузера; прохождение запроса **не доказывает доставку**. Обязательно проверить появление записи в таблице.
- Нет гарантии доступности анонимного Apps Script в России; если тест не пройдёт, заменить приёмник.
- Счётчики агрегируются по календарному дню; старые дни удаляются при следующем поступлении события. Для строгого срока удаления нужен отдельный автоматический триггер.
- Код не должен выполнять экспорт таблицы на публичный сайт и не должен собирать пользовательские параметры тренировок.
- Публикация рабочей PWA и подключение URL выполняются только после согласия владельца и QA/SECURITY.
