# Cloudflare Workers: приёмник ошибок Round Timer (проект, не развёрнут)

Для настоящих пользователей пока **не включено**. Подготовлен в изолированной ветке `setup/fast-lane-v1.3`.

## Зачем
Использовать существующий аккаунт Cloudflare — без Google-аккаунта и отдельного хостинга. GitHub Pages остаётся основным сайтом. Worker принимает только фактические ошибки; Analytics Engine хранит четыре проверенных поля: тип события, код ошибки, компонент и версия приложения. Без пользователей, IP в датасете, идентификаторов, трекинга действий, настроек или историй тренировок.

## Развёртывание — отдельно после согласия владельца
1. В Cloudflare разрешить `Account → Workers Scripts → Edit` для нового отдельного деплой-токена, не расширяя токен существующего сайта без необходимости.
2. Сохранить новый токен как отдельный секрет GitHub Actions (никогда не публиковать его).
3. Настроить GitHub Actions в изолированной ветке для тестового Worker и запустить синтетическую отправку.
4. Убедиться, что Worker доступен с iPhone без VPN и запись реально появляется в Cloudflare Analytics Engine.
5. Проверить безопасность, лимиты, подделку событий и правила конфиденциальности. Наличие `Origin` не является криптографической аутентификацией: публичный API подвержен спаму.
6. Подключить `diagnostics/sender.mjs` к тестовому PWA только после успешного приёма. Затем регрессия и отдельное разрешение на выпуск.
7. Настроить агрегированные отчёты через API Analytics Engine с отдельным токеном только для чтения.

## Ограничения
- Доступ из России неизвестен. Ошибки отправляются без влияния на таймер; при недоступности Cloudflare можно позже рассмотреть ограниченную офлайн-очередь.
- Cloudflare получает сетевые метаданные соединения, хотя код **не сохраняет** их в Analytics Engine.
- По документации Cloudflare срок хранения данных Analytics Engine — около трёх месяцев.
- Лимит Workers Free — 100000 запросов/сутки. Он не защищает от злонамеренного спама; добавить защиту от злоупотреблений до публичного включения.
- Не показывать всплывающих окон или дополнительных кнопок пользователям. Общедоступное описание минимальной диагностики можно разместить отдельно от таймера.

## Ограничение запросов (FAST LANE v1.3)
Cloudflare Workers Rate Limiting binding `ERROR_RATE_LIMIT`: приблизительно 60 принятых технических событий в минуту на местоположение Cloudflare, общий фиксированный ключ без IP и идентификаторов пользователей. Превышение → HTTP 429, без записи в Analytics Engine. Это не строгая глобальная квота и не аутентификация; возможно отправление ложных ошибок. Решение сохраняет отсутствие индивидуального отслеживания.
