## Релизы и диагностика
Рабочие изменения готовятся отдельно, проходят регрессионные тесты и объединяются в `main` только по явному разрешению владельца. Установленный на iPhone PWA проверяется в реальных условиях после выпуска.

Приложение отправляет исключительно фиксированные коды технических ошибок в Cloudflare, без истории тренировок и пользовательских идентификаторов. Информация: [конфиденциальность](site/privacy.html). Секреты/токены в этом публичном репозитории не размещаются.
