# Round Timer · APP-001

**Единая ссылка для пользователей:** https://mastyukov.github.io/round-timer/  
**Утверждённый кандидат выпуска:** v0.8.5. Адрес начнёт работать после включения GitHub Pages и успешной публикации.

Интервальный таймер для тренировок: обратный отсчёт, раунды, отдых, гонг, работа офлайн. Новые настройки: раунд по умолчанию **1:00**, ярлык iPhone **«Раунд таймер»**.

## FAST LANE v1.3
- `site/` — **единственные** файлы, публикуемые GitHub Pages.
- `tests/` — автоматические тесты (не публикуются).
- `project/` — паспорт, решения, QA, история, планы (не публикуются).
- `diagnostics/` — исходники модуля и тестов.
- `receiver/cloudflare-worker/` — отдельно развёрнутый минимальный приёмник Cloudflare Analytics Engine.
- `.github/workflows/` — QA и публикация через GitHub Actions.

**Тестовая PWA:** https://mastyukov-cyber.github.io/round-timer-pages-test/ (отдельный публичный репозиторий `mastyukov-cyber/round-timer-pages-test`).  
**Зеркало:** https://round-timer-pwa.pages.dev/ (его обновление — отдельный этап синхронизации).  
**Исторические приватные исходники:** `mastyukov-cyber/round-timer-pwa`.

## Релизы и диагностика
Рабочие изменения готовятся отдельно, проходят регрессионные тесты и объединяются в `main` только по явному разрешению владельца. Установленный на iPhone PWA проверяется в реальных условиях после выпуска.

Приложение отправляет исключительно фиксированные коды технических ошибок в Cloudflare, без истории тренировок и пользовательских идентификаторов. Информация: [конфиденциальность](site/privacy.html). Секреты/токены в этом публичном репозитории не размещаются.

## Восстановление
Контрольная точка до выпуска — стабильная v0.8.3 (в истории GitHub и архиве). При неудачном выпуске восстановить последнюю утверждённую версию файлов `site/` из сохранённого коммита и пройти тот же GitHub Actions QA → Pages deploy. Изменения сервера ошибок откатывать отдельно через версию Cloudflare Worker.
