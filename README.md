# Round Timer · APP-001

Интервальный таймер для тренировок. **Рабочий адрес после отдельной настройки GitHub Pages:** https://mastyukov.github.io/round-timer/

## Структура (FAST LANE v1.3)

- `site/` — файлы только утверждённой рабочей версии PWA; GitHub Pages будет публиковать **только эту папку**.
- `tests/` — автоматические проверки и регрессионные сценарии.
- `project/` — паспорт проекта, журнал решений, изменения, безопасность и QA.
- `scripts/` — контролируемый импорт утверждённой версии.
- `.github/workflows/` — проверки GitHub Actions.

Тестирование интерфейса и экспериментальных версий проходит **в отдельном репозитории** `mastyukov-cyber/round-timer-pages-test`. Закрытые исходники — `mastyukov-cyber/round-timer-pwa`.

**Исходный проверенный выпуск:** v0.8.3. Текущее рабочее зеркало: https://round-timer-pwa.pages.dev/.

## Безопасность выпуска

Никаких изменений в публикации без явного разрешения владельца. Не публикуем секреты, личные данные или пользовательские журналы в репозитории. Обязательные ошибки можно хранить локально, но **сетевой сбор диагностических событий ещё не реализован и не включён**. Подробности: `project/DIAGNOSTICS.md` и `project/PRIVACY.md`.
