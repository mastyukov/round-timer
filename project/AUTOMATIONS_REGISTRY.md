## Общие правила результатов

- Отсутствие новых диагностических Issues **не доказывает**, что мониторинг выполнился: обязательно проверять завершённый scheduled run и доступность Cloudflare.
- Тест `fetch` + синтетический Worker подтверждает алгоритм, но не доставку ошибок с пользователей.
- GitHub PR CI проверяет код и тестовую модель браузера, не реальный Safari на iPhone.
- Совпадение HEAD двух зеркал ещё не означает успешное восстановление, его необходимо проверять клонированием и прогоном тестов.
- Смена работающих расписаний, токенов, уведомлений и основной публикации — только по отдельному решению владельца.
