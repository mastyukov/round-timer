# FAST LANE v1.3 — базовая структура для небольших PWA

Каждое приложение получает `APP-NNN`, короткое имя на английском и отдельный постоянный пользовательский URL.

- **Исходники:** отдельный закрытый репозиторий, если нужны секреты/разработка.
- **Публичный рабочий репозиторий:** `site/`, `tests/`, `project/`, `.github/workflows/`.
- **Тестовая версия:** отдельный репозиторий и URL, не распространяемый пользователям.
- **Основной хостинг:** GitHub Pages, через Action, который загружает только `site/`.
- **Зеркало:** Cloudflare Pages по отдельному разрешённому выпуску.
- **Публикация:** QA PASS + явное одобрение. Не автоматизировать выпуск на каждый push из непроверенной ветки.
- **Логи:** минимальные, без персональных идентификаторов, с прозрачностью и согласием для необязательной аналитики; без попапов в ходе тренировки.
- **Отчёт:** что изменено, что проверено, тесты и фактические ошибки, следующий шаг.
- **Откат:** хранить предыдущий проверенный release и зафиксировать процедуру возврата до массового запуска.

Структура примерная для маленьких публичных PWA, не заменяет строгие правила приложений с пользовательскими данными.
