## Что именно тестируется

- Чистый расчёт движка: границы подготовки/работы/отдыха/раундов, нулевые интервалы, бесконечные раунды, восстановление по времени.
- Синтетическая DOM-модель: старт, пауза, продолжение, сброс, восстановление, гонг после задержанной загрузки.
- Отдельный `audio-guard`: асинхронный старт и отмена по паузе/сбросу/скрытию.
- Service Worker модель: полное офлайн-открытие после кеширования, кеш-first при недоступной/зависшей сети, обновление версии без смешивания, сохранность старого кеша при неполной загрузке.
- Локальная очередь: максимальное число/размер/TTL/число попыток; недоступный storage; HTTP 204 vs 202/opaque; стабилизация ID; зависшая сеть не мешает таймеру.
- Worker (модель): CORS, лимит, проверка фиксированного состава, KV последовательная дедупликация и fail closed, совместимость старого payload.
- Python: периодичность мониторинга, ошибки API, дубли GitHub Issues, ограничение кодов.
- Связность восстановления SourceCraft: отдельный clone, `git fsck`, запуск тестов **именно из восстановленной копии**.
