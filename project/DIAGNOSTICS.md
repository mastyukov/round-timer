# Диагностика Round Timer

**Утверждено 08.11.2026:** автоматический сбор только технических ошибок, без статистики использования и без дополнительных окон/кнопок. Владелец подтвердил выпуск.

## Что отправляем
Только: `app_error`, `asset_error`, `audio_failure`. Для каждого события — фиксированный код ошибки, компонент, версия приложения. До 5 событий за один запуск PWA, без отложенной очереди.

Не отправляем: начало/конец тренировки, параметры занятий, пользовательские идентификаторы, имена, телефоны, email, IP в полезной нагрузке, произвольный текст ошибок, stack trace, пользовательские URL, GPS, UA или cookies. При отсутствии сети отправка просто завершается с отказом — отсчёт продолжает работу.

## Хранилище
- Worker: `https://round-timer-error-receiver.mastyukov.workers.dev/v1/error`.
- Cloudflare Analytics Engine dataset: `round_timer_error_events`, binding: `ERROR_EVENTS`.
- В событии сохраняются только четыре строковых кода; время обработки ставит сам Cloudflare. Срок хранения определяется сервисом (до трёх месяцев).
- `ERROR_RATE_LIMIT`: приблизительно 60 принятых запросов/минуту на локацию Cloudflare, единый ключ без IP-адресов/идентификаторов. Превышение HTTP 429; ограничение приблизительное и не защищает от всех подделок.
- Перечень разрешённых сайтов задаётся в коде Worker. Origin не является криптографической аутентификацией.
- Сервер Cloudflare технически получает сетевые метаданные, включая IP на транспортном уровне; в Analytics Engine IP не записывается.

## Результаты
- Worker записал одну синтетическую ошибку и вернул 204; чужой Origin → 403, статистика тренировок → 400, пустой публичный маршрут → 404.
- Сигнал v0.8.5 после проверки пользователем на iPhone изменил агрегированный счётчик с 0 на 1.
- Повторное обновление приёмника с rate-limit прошло локальные и реальные smoke-тесты; GitHub Actions `42508397821`.
- Конфиденциальность описана на публичной странице `site/privacy.html` без изменения UI.
- Испытания с реальными пользователями после выпуска и проверки разных сетей остаются следующим этапом.
