## Открытые вопросы
- Сервис Cloudflare Worker может быть недоступен без VPN из некоторых российских сетей; успешный тест и QA не гарантируют всеобщую доставку.
- Origin — не криптографическая защита от подделки отчётов. Антиспам/политика хранения требуют доработки до массового включения.
- Отложенная аудиозадержка при мгновенной паузе из предыдущей версии не исправлялась.
- Отсутствует финальная проверка UX/офлайн на самом телефоне для v0.8.5.
