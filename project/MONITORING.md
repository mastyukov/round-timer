# Round Timer — мониторинг ошибок раз в 3 дня

**Статус:** реализация и проверки в изолированной ветке. До утверждения слияния в main расписание не работает.

## Расписание
GitHub Actions запускает короткую проверку календарной даты ежедневно в 18:27 UTC (21:27 МСК), но **обращается к Cloudflare только каждые 3 дня**, начиная с 11 ноября 2026 года. Это позволяет сохранять трёхдневный интервал при смене месяца. Запуски GitHub Actions могут задерживаться или пропускаться — система не предназначена для экстренных оповещений.

## Что читает
Только агрегированное количество технических ошибок за 72 часа по четырём полям: тип, фиксированный код, компонент, версия. Нет IP, имён, идентификаторов телефонов, истории и параметров тренировок. Количество событий **не равно** количеству людей.

## Когда уведомляет
- Ошибок нет — GitHub Issues не меняются.
- Новый тип ошибки — создаётся Issue с меткой `round-timer-diagnostics` и упоминанием `@mastyukov-cyber`.
- Повторение на следующей трёхдневной проверке — комментарий к существующей Issue. Закрытая Issue вновь открывается.
- Повторный запуск в ту же дату не создаёт дубликатов.
- Сбой чтения Cloudflare вызывает FAIL в GitHub Actions; владелец должен разрешить уведомления о сбоях Actions.

## Как получать уведомления
Войдите под владельцем GitHub в https://github.com/mastyukov/round-timer и выберите **Watch → All Activity** (или подписку на Issues). В https://github.com/settings/notifications включите уведомления на выбранном устройстве или по email. Доставка не доказана до фактической проверки первого уведомления.

Ошибки: https://github.com/mastyukov/round-timer/issues?q=label%3Around-timer-diagnostics

## Границы безопасности
Все токены остаются в GitHub Actions Secrets; новые секреты не требуются. GitHub Actions получает `issues:write` для создания уведомлений. Запуски по push в изолированную ветку и вручную — **только dry-run**: без изменений GitHub Issues. Только автоматический `schedule` в основной ветке создаёт/обновляет Issues. Исправления и новые релизы без отдельного подтверждения не выполняются.
