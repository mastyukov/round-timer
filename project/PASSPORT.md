# Паспорт — APP-001 Round Timer

**Контрольная точка:** 2026-11-08 · **Версия:** v0.8.3 · **FAST LANE:** v1.3

**Назначение:** интервальные тренировки с обратным отсчётом, подготовкой, раундами, отдыхом, гонгом и звуковыми предупреждениями.

**Платформы:** установленный PWA и браузер на iPhone/iPad/Mac. После первой успешной загрузки приложение должно запускаться офлайн при сохранённом кэше.

**Планируемый единый адрес для пользователей:** https://mastyukov.github.io/round-timer/ (ещё не включён на момент подготовки документов).

**Площадки:** отдельный тестовый GitHub Pages `mastyukov-cyber/round-timer-pages-test`; резервное зеркало Cloudflare https://round-timer-pwa.pages.dev/; исходники в приватном `mastyukov-cyber/round-timer-pwa`.
