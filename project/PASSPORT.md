# Паспорт — APP-001 Round Timer

**Дата:** 08.11.2026. **FAST LANE:** v1.3. **Кандидат рабочего выпуска:** v0.8.5.

**Назначение:** PWA спортивного интервального таймера с подготовкой, раундами, отдыхом, гонгом и звуковыми предупреждениями, без аккаунтов. Установка на iPhone/iPad, работа в браузере на Mac и без сети после первоначальной загрузки.

**Единый рабочий URL:** https://mastyukov.github.io/round-timer/ (публикация в процессе; проверить фактическую доступность).

**Тестовый URL:** https://mastyukov-cyber.github.io/round-timer-pages-test/ (не распространять пользователям).

**Резервное зеркало:** https://round-timer-pwa.pages.dev/ (пока может оставаться на предыдущем выпуске до отдельной синхронизации).

**Исходники:** рабочая публичная версия `mastyukov/round-timer/site/`; старые приватные исходники `mastyukov-cyber/round-timer-pwa`.

**Тестирование:** `tests/`, GitHub Actions; выпуск только по явному разрешению владельца. Отдельный источник фоновых ошибок: Cloudflare Worker + Analytics Engine. Никаких пользовательских идентификаторов, истории тренировок, новых кнопок или окон.

**Наблюдаемые ограничения:** GitHub Pages без собственного домена требует начального включения Pages в настройках репозитория, Cloudflare Worker может быть недоступен из некоторых российских сетей; ошибка задержанного гонга при быстрой паузе остаётся открытой.
