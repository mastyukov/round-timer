# История Round Timer

## v0.8.5 — 08.11.2026 · утверждённый кандидат
- Раунд по умолчанию: 60 секунд.
- Новый ярлык на домашнем экране iPhone: «Раунд таймер».
- Минимальная отправка реальных технических ошибок в отдельный Cloudflare Worker (в пределах 5 за запуск).
- Одноразовый тестовый URL `?diag_test=1` полностью удалён из кандидата для пользователей.
- Документация обработки данных на отдельной странице `privacy.html` без новых окон и кнопок.
- Проверяемая структура FAST LANE, публикуется только `site/`.
- Антиспам-ограничение на приёмнике: примерно 60 событий/минуту на локацию Cloudflare, без идентификации устройств.

## v0.8.4 — тестовая
- Добавлены отправитель минимальных ошибок и офлайн-кэш модулей диагностики.
- На iPhone подтверждена работа, серверная синтетическая запись проверена.

## v0.8.3 — прежняя стабильная
- Service Worker cache-first, работа офлайн на iPhone.
- Cloudflare Pages и тестовый GitHub Pages успешно проверены.

## FAST LANE v1.3
- `site/`, `tests/`, `project/`, GitHub Actions, отдельная тестовая PWA.

Изменения других версий не считаются выпущенными, пока не получено подтверждение GitHub Pages и реальная проверка сайта.
